# Brain-Tumor-Detection
MRI görüntülerinden beyin tümörü tespiti ve sınıflandırması için VGG19 ve ResNet50 modelleri kullanılmıştır. Görüntü ön işleme teknikleri uygulanmış, React ve FastAPI ile kullanıcıların MRI görüntülerini yükleyip tahmin sonuçlarını görüntüleyebildiği bir web uygulaması geliştirilmiştir.
